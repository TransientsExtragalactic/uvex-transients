Transient Characterization
==========================

A detection is not yet a characterization. These pages apply the standard selection cuts to the
detected events, to keep the ones with enough repeat detections, a bright enough peak and a tightly
bracketed explosion time to be classified, and then repeat the detection analysis on what is left.

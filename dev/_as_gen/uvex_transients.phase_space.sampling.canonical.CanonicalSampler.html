CanonicalSampler#

class uvex_transients.phase_space.sampling.canonical.CanonicalSampler(schedule: SurveySchedule, mission=None, *, spectral_index: float | None = None, rise_ratio: float | None = None, fade_mag: float | None = None, cosmology: Cosmology | None = None, schedule_name: str | None = None, **survey)[source]#

Count the recoveries of a canonical transient at points of the luminosity-half-decline-time plane.

The transient has a fast-rise, exponential-decay light curve and a power-law spectrum (see _CanonicalTransient). A point is x = (log10 L_band / (erg/s), log10 t_half / day). \(L_\mathrm{band}\) is the peak rest-frame luminosity emitted in the band, \(L_\nu\Delta\nu\) for the equivalent bandwidth \(\Delta\nu\) of the band with \(L_\nu\) taken at its effective frequency. One sampler makes the map of one band.

Both axes are derived quantities, not parameters of the SED, so this sampler places a point itself instead of binding axes to parameters.

Every argument that is None (the default) takes config["phase_space.canonical.<name>"] for the shape of the transient, and what SurveySettings resolves for the rest.

Parameters:

  • schedule (SurveySchedule) – The survey to recover events against.

  • mission (str or m4opt.missions.Mission, optional) – The mission (detector and background), or the name of one.

  • spectral_index (float, optional) – The index \(\alpha\) of the spectrum, \(L_\nu\propto\nu^\alpha\), which sets the K-correction \((1+z)^{1+\alpha}\). A spectrum rising steeply to the blue (about 3) has no redshift limit and raises ValueError.

  • rise_ratio (float, optional) – The ratio of the rise to the decay time of the light curve.

  • fade_mag (float, optional) – How far below its peak, in magnitudes, an event is followed by the survey.

  • cosmology (Cosmology, optional) – Defaults to the configured cosmology.

  • schedule_name (str, optional) – The registry name of schedule, recorded in settings so that from_settings() can fetch the same schedule.

  • **survey – What counts as a recovery and how a point is simulated: band (the one that recovers events and in which the luminosity is measured), snr_threshold, n_visits, exclude_first_visit_detections, detection, mag_limit, time_bins, nside and order. See SurveySampler and SurveySettings.

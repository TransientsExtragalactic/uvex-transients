uvex_transients.models.shock_cooling.inverse_gamma.InverseGammaBlackbodySED.get_effective_peak_magnitudes#

InverseGammaBlackbodySED.get_effective_peak_magnitudes(z_grid: NumericalInput, bandpasses: Mapping[str, SpectralElement] | Sequence[SpectralElement], *, t_rest: Quantity | None = None, t_min: Quantity | None = None, t_max: Quantity | None = None, n_time: int = 200, criterion: Literal['any', 'all', 'k_of_n'] = 'any', k: int | None = None, n_samples: int = 1000, cosmology: FLRW | None = None, chunk_size: int | None = None, progress: bool = True, rng: RNGInput = None) → EffectivePeakGrid#

Evaluate a sampled population’s effective peak magnitude at every redshift of a grid.

This is the expensive half of the detection-horizon calculation, and it does not depend on any magnitude limit. The method is that of ~uvex_transients.models.core.detection_horizon.effective_peak_grid.

Parameters:

  • z_grid (float or array-like) – Redshifts, strictly increasing and positive, reaching past the horizon.

  • bandpasses (Mapping[str, SpectralElement] or sequence of SpectralElement) – The bands in which an event may be detected.

  • t_rest (Quantity, optional) – Rest-frame times since explosion. If omitted, a logarithmic grid from t_min to t_max is used.

  • t_min (Quantity, optional) – The ends of that grid.

  • t_max (Quantity, optional) – The ends of that grid.

  • n_time (int, optional) – Number of points of the grid. The default is 200.

  • criterion ({"any", "all", "k_of_n"}, optional) – How the bands combine. The default is "any".

  • k (int, optional) – The number of bands required for "k_of_n".

  • n_samples (int, optional) – Number of draws from the priors. The default is 1000.

  • cosmology (FLRW, optional) – Defaults to the configured cosmology.

  • chunk_size (int, optional) – Draws evaluated per step; it does not change the result.

  • progress (bool, optional) – Whether to show a progress bar. The default is True.

  • rng (numpy.random.Generator, int or None, optional) – Random-number source for the draws.

Returns:

The (n_samples, Z) effective peak magnitudes with the grids and parameters that produced them.

Return type:

EffectivePeakGrid

See also

get_observability_curve

Turn the grid into a horizon for each magnitude limit.

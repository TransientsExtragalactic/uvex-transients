SurveySampler#

class uvex_transients.phase_space.sampling.core.SurveySampler(schedule: SurveySchedule, mission=None, *, band: str | None = None, snr_threshold: float | None = None, n_visits: int | None = None, exclude_first_visit_detections: bool | None = None, detection: Sequence[Mapping] | None = None, mag_limit: float | None = None, time_bins: int | None = None, nside: int | None = None, order: str | None = None, cosmology: Cosmology | None = None, schedule_name: str | None = None)[source]#

Count the recoveries of a transient simulated against a survey: what every survey-backed sampler shares.

A subclass is built in its own __init__, which calls super().__init__ and then _configure() once, with its space, the redshift out to which the volume is tabulated and the settings it adds to the ones recorded here. It supplies make_transient(), redshift_limit(), _place() and _log_window(). If its axes are parameters of the SED, it lists them in parameter_axes, a tuple of ParameterAxis, and _place() calls _fix_parameters() for them and only sets the window and the redshift limit itself.

Every setting that is None (the default) takes its default from the configuration, which is resolved once by SurveySettings: config["phase_space.<kind>.<name>"] if the kind of the sampler (or a kind it is built on) has the key, else config["phase_space.detection.<name>"] or config["phase_space.simulation.<name>"]. A subclass takes these as **survey and passes them on, so a new survey setting is added in this one place.

Parameters:

  • schedule (SurveySchedule) – The survey to recover events against.

  • mission (str or m4opt.missions.Mission, optional) – The mission (detector and background), or the name of one.

  • band (str, optional) – The detector band that recovers events.

  • snr_threshold (float, optional) – The signal-to-noise a visit must reach.

  • n_visits (int, optional) – How many visits must reach it.

  • exclude_first_visit_detections (bool, optional) – Whether a detection that is only on a field’s first visit is discarded; see SurveySimulator.filter_by_snr.

  • detection (sequence of Mapping, optional) – What counts as a recovery, as a list of the simulator’s registered cuts (see check_detection()). By default one snr cut, which is the three settings above. A cut that takes snr_threshold, n_visits, exclude_first_visit_detections or bands and is not given them gets the sampler’s, with bands the band of the map. A rule that is not a list of cuts is written by overriding detect().

  • mag_limit (float, optional) – The AB depth that sets the redshift limit of a point. Only events brighter than it are drawn.

  • time_bins (int, optional) – Number of equal explosion-time bins spanning the survey; see SurveySimulator.sample_N_events.

  • nside (optional) – HEALPix resolution of the sampling grid; the package defaults if omitted.

  • order (optional) – HEALPix resolution of the sampling grid; the package defaults if omitted.

  • cosmology (Cosmology, optional) – Defaults to the configured cosmology.

  • schedule_name (str, optional) – The registry name of schedule (see get_schedule()), recorded in settings so that from_settings() can fetch the same schedule. Leave it out for a schedule that is not in the registry.

Notes

The tables a sampler interpolates (volume, exposure) are sized by config["phase_space.numerics"]. They set the precision of the scales, not what is measured, so they are not recorded in settings.

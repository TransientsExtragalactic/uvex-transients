uvex_transients.transients.horizon#

Stored detection-horizon curves of the transient classes.

A HorizonCurve is the redshift limit \(z_L(m)\) of a transient population as a function of the AB magnitude limit \(m\): beyond \(z_L\), with 95% confidence, at most 1% of events drawn from the SED’s priors are brighter than \(m\) in either UVEX band, and never beyond the redshift where the Lyman limit enters the NUV band. The calculation is in uvex_transients.models.core.detection_horizon; this module stores and checks its result.

A curve takes seconds to a minute to compute, so each shipped class stores its own as horizon_curves/<ClassName>.ecsv, which ~uvex_transients.transients.base.ExtragalacticTransient.horizon_curve reads. A custom class, or a shipped one whose priors or duration changed, generates its curve on first use. Which is which is decided by a fingerprint, a fixed-seed draw from the class’s priors and its duration, stored with the curve and compared on use. make horizons rebuilds the stored files, and the test suite fails, naming the class, when one is stale.

Attributes

CURVE_DIR

Directory holding the stored curve of every shipped transient class.

MAG_LIMITS

The single-dwell AB depths a curve is tabulated at.

SETTINGS

The settings a stored curve is generated with, recorded in its metadata.

T_MIN

Earliest rest-frame time of the light-curve grid (86 s).

Z_MIN

Smallest redshift of the grid (about 13 Mpc).

SEED

Seed of every random draw, so that generating a curve twice gives the same table.

Functions

curve_path(name)

Return where the stored curve of a transient class lives.

fingerprint(transient)

Summarize the part of a transient that its curve depends on: the duration and the priors.

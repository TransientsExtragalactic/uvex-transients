uvex_transients.models#

Spectral modeling infrastructure for generating synthetic photometry.

Modules

arnett

Utilities for computing Arnett-style (diffusion-limited) bolometric lightcurves.

core

Core SED framework (models, parameters, priors) shared by every transient class.

host_dust

Host-galaxy dust as part of an SED model.

kilonovae

Composite kilonova SED models.

lfbots

Composite LFBOT (Luminous Fast Blue Optical Transient) SED models.

lightcurves

Generic, reusable bolometric light-curve shapes.

shock_cooling

Analytic shock cooling emission models.

spectra

Frequency-dependent spectral shape models.

supernovae

Composite supernova SED models.

tdes

Composite tidal disruption event SED models.

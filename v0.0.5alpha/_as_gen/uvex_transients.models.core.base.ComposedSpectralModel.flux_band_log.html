uvex_transients.models.core.base.ComposedSpectralModel.flux_band_log#

classmethod ComposedSpectralModel.flux_band_log(nu: Quantity, throughput: NumericalInput, t: Quantity, *, redshift: PhysicalInput | None = None, luminosity_distance: Quantity | None = None, angular_diameter_distance: Quantity | None = None, proper_distance: Quantity | None = None, cosmology: FLRW | None = None, log_attenuation: NumericalInput | None = None, **parameters: ParameterValue) → FloatResult#

Natural log of the band-averaged observed flux density, given physical-unit inputs.

Parameters:

  • nu (Quantity) – Observed frequency grid to integrate over. Need not be sorted.

  • throughput (array-like) – Dimensionless bandpass response at each nu sample.

  • t (Quantity) – Observed time since explosion.

  • redshift (array-like or Quantity, optional) – See flux_log().

  • luminosity_distance (Quantity, optional) – See flux_log().

  • angular_diameter_distance (Quantity, optional) – See flux_log().

  • proper_distance (Quantity, optional) – See flux_log().

  • cosmology (FLRW, optional) – See flux_log().

  • log_attenuation (array-like, optional) – See flux_band_log_cgs().

  • **parameters – This model’s parameter values. See eval_log_cgs().

Returns:

The natural log of \(\\bar{F}_\\nu\), in erg/s/cm^2/Hz.

Return type:

numpy.ndarray or float

Raises:

TypeError – If nu/t are not Quantities with frequency/time units.

*******************************
Transient Summaries
*******************************

.. card::
   :class-card: sd-shadow-sm gallery-banner

   *Module:* :mod:`~uvex_transients.utils.summary_report`

   One page per transient family, each built from the event summary table of the latest release: the
   detection funnel, the expected number of events, the distributions of the selected events, their
   sky positions and an example light curve. Pages whose data cannot be obtained skip the cells that
   need it, so a build without network access, or against a release that predates the summary table,
   still succeeds.
